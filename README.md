# CajeroAutomaticoKotlin
Este proyecto está realizado por Miguel Bedmar Diaz de la Serna alumno cursando segundo de desarrollo
de aplicaciones multimedia.

# 📋Descripcion.
Se desarrollara una aplicación en el lenguaje de programación kotlin 
por consola en donde se simule la interracción de un cajero automático
. En este proyecto se trabajara el control de salida de bucles , condiciones
y excepciones con try catch.

# 🎯Objetivo.
El objetivo de este proyecto es que  el programa permita consultar
saldo, ingresar dinero, retirar dinero y finalizar la operación de forma controlada

# ⛷️Fases del Proyecto.
Para el correcto desarrollo el proyecto se desarrollara en siete fases que serán las siguientes.

-   FASE 1: Creación de proyecto kotlin
-   FASE 2: Inicializar el saldo inicial con 500.
-   FASE 3: Función Menu principal.
-   FASE 4: Función consulta de Saldo.
-   FASE 5: Metodo Ingresar Dinero.
-   FASE 6: Metodo Retirar Dinero.
-   FASE 7: Control de Errores.
